# 🏠 우리집 인벤토리

집 안 물건들을 3D 픽셀(도트) 스타일로 한눈에 보고 관리하는 웹앱입니다. 집 구조(방)를 돌려보면서
물건을 클릭하면 상세 정보 레이어가 뜨고, 장바구니에 담거나 당근마켓용 판매 글 초안을 만들 수 있어요.

## 주요 기능

- **3D 집 구조**: 거실 / 주방 / 침실 / 욕실 4개 방을 아이소메트릭 카메라로 둘러볼 수 있어요
  (드래그로 회전, 스크롤로 확대/축소). 픽셀레이션 후처리와 도트 폰트([Galmuri](https://galmuri.quiple.dev))로
  포켓몬류 게임 같은 귀여운 느낌을 냈습니다.
- **물건 마커 클릭 → 상세 레이어**: 방에 놓인 물건 아이콘을 클릭하면 이름/카테고리/수량/가격/구매일/메모가
  담긴 팝업(대화창 스타일)이 뜹니다. 여기서 수량을 바로 조절하거나 삭제할 수 있어요.
- **장바구니**: 상세 레이어에서 "장바구니 담기"를 누르면 우측 장바구니 목록에 쌓입니다. 정리할 물건을
  모아두는 체크리스트처럼 사용하세요.
- **당근마켓 등록 초안**: 물건 하나 또는 장바구니에 담은 여러 물건을 한번에 소개하는 판매 글 초안을
  자동으로 만들어줍니다. 당근마켓은 외부 앱의 자동 등록 API를 제공하지 않기 때문에, 초안을 복사해서
  당근마켓 앱/웹의 "글쓰기"에 붙여넣는 방식으로 동작해요.
- **물건 추가**: 상단 "+ 물건 추가"로 새 물건을 방/카테고리/수량/가격/상태/메모와 함께 등록할 수 있습니다.
- 모든 데이터는 브라우저 `localStorage`에 저장됩니다 (별도 백엔드 없음).

## 기술 스택

- React + TypeScript + Vite
- [react-three-fiber](https://github.com/pmndrs/react-three-fiber) / drei / postprocessing (3D 씬 + 픽셀레이션 효과)
- zustand (+ persist 미들웨어로 localStorage 저장)
- Galmuri 도트 폰트 (OFL 라이선스, `public/fonts`)

## 개발 실행

```bash
npm install
npm run dev
```

## 빌드

```bash
npm run build
```

## 코드 구조

```
src/
  components/scene/   3D 씬 (방 바닥, 물건 마커, 카메라, 픽셀레이션)
  components/ui/      오버레이 UI (상세 레이어, 장바구니, 모달들)
  store/               zustand 인벤토리 스토어
  data/                방 레이아웃 정의 + 초기 예시 물건 데이터
  utils/               아이콘 텍스처 생성, 당근마켓 초안 텍스트 생성
```

# 🏠 우리집 인벤토리

집 안 물건들을 3D로 한눈에 보고 관리하는 웹앱입니다. 집 구조(방)를 돌려보면서 물건을 클릭하면
상세 정보 레이어가 뜨고, 다 쓴 물건은 장바구니에 담아 재구매하거나, 필요 없는 물건은 판매함에
담아 당근마켓용 판매 글 초안을 만들 수 있어요.

## 주요 기능

- **3D 집 구조**: 방들을 아이소메트릭 카메라로 둘러볼 수 있어요 (드래그로 회전, 스크롤로 확대/축소).
  밝고 부드러운 색감과 [Jua](https://fontsource.org/fonts/jua)(포인트) + [Pretendard](https://cactus.tistory.com/306)(본문)
  폰트 조합으로 깔끔하면서도 귀여운 느낌을 냈습니다.
- **도면 에디터 ("🏗️ 집 구조")**: 네이버 부동산·Zillow 등에서 찾은 우리 집 도면을 직접 스크린샷으로
  저장해 업로드하면 배경 참고 이미지로 깔아주고, 그 위에 마우스 드래그로 방 사각형을 그려서 실제 집
  구조에 맞는 방 배치를 만들 수 있어요. (두 사이트 모두 도면을 공개 API로 제공하지 않고 자동 스크래핑은
  이용약관 위반이라, 자동 수집 대신 "직접 캡처한 이미지를 트레이싱"하는 방식을 택했습니다.) 이미지를
  올리면 기존 방 구성은 지우고 새로 그릴지 물어봐요. 이미지 없이 바로 그려도 되고, 기본 4개 방
  (거실/주방/침실/욕실) 템플릿에서 시작해 수정할 수도 있어요.
- **물건 마커 클릭 → 상세 레이어**: 방에 놓인 물건 아이콘을 클릭하면 이름/카테고리/수량/가격/구매일/메모가
  담긴 팝업이 뜹니다. 여기서 수량을 바로 조절하거나 삭제할 수 있어요.
- **🛒 장바구니 (재구매 목록)**: 다 써서 다시 사야 할 물건을 담아두는 곳이에요. "다시 구매하기"로
  담고, 쿠팡·네이버쇼핑 검색 링크로 바로 주문하러 가고, "샀어요"를 누르면 담아둔 수량만큼 재고에
  자동으로 채워집니다.
- **🥕 판매함 (당근마켓 정리함)**: 필요 없어진 물건을 모아두는 곳이에요. 물건 하나만 바로 등록 초안을
  만들 수도 있고, 판매함에 쌓인 여러 물건을 한번에 소개하는 글도 만들 수 있어요. 당근마켓은 외부 앱의
  자동 등록 API를 제공하지 않기 때문에, 초안을 복사해서 당근마켓 앱/웹의 "글쓰기"에 붙여넣는 방식으로
  동작해요.
- **물건 추가**: 상단 "+ 물건 추가"로 새 물건을 방/카테고리/수량/가격/상태/메모와 함께 등록할 수 있습니다.
- 모든 데이터는 브라우저 `localStorage`에 저장됩니다 (별도 백엔드 없음).

## 기술 스택

- React + TypeScript + Vite
- [react-three-fiber](https://github.com/pmndrs/react-three-fiber) / drei / postprocessing (3D 씬, Bloom 효과)
- zustand (+ persist 미들웨어로 localStorage 저장)
- Jua + Pretendard 폰트 (둘 다 OFL 라이선스, `public/fonts`에 자체 호스팅)

## 개발 실행

```bash
npm install
npm run dev
```

## 빌드

```bash
npm run build
```

## 코드 구조

```
src/
  components/scene/   3D 씬 (방 바닥, 물건 마커, 카메라, 구름, Bloom 효과)
  components/ui/      오버레이 UI (상세 레이어, 장바구니/판매함 드로어, 도면 에디터, 모달들)
  store/               zustand 인벤토리 스토어 (방 레이아웃 + 물건 + 장바구니 + 판매함)
  data/                기본 방 레이아웃(템플릿) + 초기 예시 물건 데이터
  utils/               아이콘/그림자 텍스처 생성, 당근마켓 초안 텍스트 생성, 쇼핑 검색 링크, 색상 유틸
```
